Ejercicio 9 — Instrucciones generales (Generación de un stub Node.js a partir de OpenAPI/Swagger)

Instalar el generador de código OpenAPI
Instala la herramienta oficial para generar código a partir de especificaciones OpenAPI:

npm install -g @openapitools/openapi-generator-cli


Preparar el archivo OpenAPI
Asegúrate de disponer de un archivo .yaml o .json que describa tu API según el estándar OpenAPI.

Generar el proyecto Node.js Express a partir del archivo OpenAPI
Ejecuta el comando general:

openapi-generator-cli generate -i ./ruta/al/archivo.yaml -g nodejs-express-server -o ./carpetaDestino


-i indica el archivo OpenAPI.

-g define el generador (Node.js + Express).

-o la carpeta donde se generará el stub.

Revisar la estructura generada
El proyecto generado incluirá, entre otros:

Controladores vacíos listos para implementar.

Servicios donde colocar la lógica de negocio.

El archivo OpenAPI incluido dentro del proyecto.

Un README.md con instrucciones de ejecución.

Instalar Swagger UI si se requiere documentación interactiva
Si el stub no incluye Swagger UI:

npm install swagger-ui-express yamljs


Implementar la lógica de negocio en los servicios o controladores generados
Completa las funciones generadas automáticamente con la lógica concreta del proyecto (validaciones, acceso a datos, respuestas, etc.).

Ejecutar el servidor generado
Normalmente:

npm start


Probar la API desde el navegador o el editor OpenAPI
Accede a la ruta donde se expone la documentación, típicamente:

http://localhost:8080/api-docs


Desde ahí puedes probar los endpoints generados.

Ejercicio 10 — Instrucciones generales (Generación de una API con acceso a BD a partir de OpenAPI)

Preparar la base de datos

Crea o importa la base de datos necesaria para tu proyecto.

Asegúrate de que contiene las tablas que la API debe gestionar.

Configura el acceso mediante un usuario con permisos adecuados.

Diseñar la API en OpenAPI

Define en un archivo .yaml o .json todas las operaciones CRUD necesarias.

Asocia cada operación a su método HTTP correspondiente (GET, POST, PUT, DELETE).

Incluye esquemas de datos (models), parámetros, respuestas, y códigos de estado.

Generar el stub de servidor a partir de la definición OpenAPI
Igual que en el ejercicio anterior:

openapi-generator-cli generate -i ./api.yaml -g nodejs-express-server -o ./apiGenerada


Instalar dependencias del proyecto generado
Entra en la carpeta generada e instala:

npm install


Añadir librerías para acceso a base de datos
Instala, por ejemplo:

Para MySQL: mysql2

Para PostgreSQL: pg

Para SQLite: sqlite3
Ejemplo:

npm install mysql2


Configurar la conexión a base de datos
Crea un módulo de conexión o usa uno existente:

Indica host, usuario, contraseña, BD, etc.

Maneja errores de conexión y reconexiones si es necesario.

Implementar la lógica de negocio
En los archivos de controller o service generados automáticamente:

Implementa las consultas a la base de datos.

Añade validaciones.

Gestiona respuestas y códigos de error.

Asegura la sanidad de los datos de entrada.

Probar la API desde la documentación generada
Tras iniciar el servidor con:

npm start


Accede a la documentación interactiva para probar el CRUD:

http://localhost:<puerto>/api-docs


Realizar pruebas externas si procede
Puedes usar herramientas como Postman, Thunder Client o cURL para validar las operaciones.
